- 【**问题分析**】边进行编译边使用 `sudo  hrut_somstatus` 监控温度，发现温度一度超过 85°C 
- 【**问题状态**】 ⏳ 跟进中
- 【**问题方案**】

    - [x] 写一个脚本监控 CPU 温度，超过 70°C 时，终止一切终端上正在运行的命令 (已完成: `scripts/thermal_guard.bash`)
    - [x] 针对本次情况设计一个散热器，永久解决这个问题

        - 定性目标
            - 将 RDK X5 CPU 在室温 24°C 的情况下，控制在 50°C 以内。
            - 温升控制：目标温升 $\Delta T \leq 26°C$。

        - 设计参数
            - **热源参数**：
                - CPU 最大热功耗 (TDP)：约 10W - 12W。
                - 芯片表面积：需精确覆盖 SoC 核心区域（约 16x16mm）。
            - **散热约束**：
                - 总热阻要求：$R_{total} < 2.1 K/W$。
                - 空间限制：避开 40-pin 扩展接口、CSI 摄像头接口。
                - 电力供给：风扇需支持 5V PWM 调速。

        - 知识回忆
            - **热量定义式**：$Q = \frac{\Delta T}{R}$。
            - **导热**：以热传导为主的热传递现象。
            - **对流换热**：包含热传导、热对流两种基本热传导方式为主的热传递现象
            - **散热链路**：CPU硅片-> 散热器基板 -> 散热翅片 -> 空气。

        - 器件选型
            - **散热片 (Heatsink)**：
                - 类型：铝制铲齿散热片或密齿型材散热片。
                - 规格: 14x14x6mm（详见：docs/dev_manuals/radiator/heat_sink.png）
            - **风扇 (Fan)**：
                - 类型：鼓风机
                - 规格：1804型，尺寸为 18x18x4 mm
                - 性能：CFM 0.2,SP 5.16mmAq（详见：docs/dev_manuals/radiator/fan_RFB1804D.jpg）
            - **导热介质 (TIM)**：
                - 选型：自带导热背胶
                - 性能：不详 

        - 设计目标
            - **待机状态**：空载温度 $\leq 35°C$。
            - **满载压力测试**：4核满载持续 30 分钟，最高温 $\leq 49°C$。
            - **调速曲线**：45°C 触发起转，55°C 达到 100% 占空比。

Linux swap file 创建启用命令流

```bash
# 1. 创建 4GB 的 Swap 文件
sudo fallocate -l 4G /swapfile
# 2. 修改权限
sudo chmod 600 /swapfile
# 3. 格式化为 Swap
sudo mkswap /swapfile
# 4. 启用 Swap
sudo swapon /swapfile
```
