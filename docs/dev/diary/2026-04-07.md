## 5.2 代理跟随

往 ~/.bashrc 添加以下内容，启用命令行代理跟随功能，默认代理的流量端口为 SSH 主机的 7890 端口。

```bash
# 从 SSH 连接信息中自动提取客户端（Windows）的 IP
if [ -n "$SSH_CLIENT" ]; then
    # 提取 SSH_CLIENT 变量中的第一个字段（即客户端 IP）
    WINDOW_IP=$(echo $SSH_CLIENT | awk '{print $1}')
    export http_proxy="http://$WINDOW_IP:7890"
    export https_proxy="http://$WINDOW_IP:7890"
fi


#  终端连接时自动配置 Git 代理
if [ -n "$https_proxy" ]; then
    git config --global http.proxy "$https_proxy"
fi

if [ -n "$https_proxy" ]; then
    git config --global https.proxy "$https_proxy"
fi
```
