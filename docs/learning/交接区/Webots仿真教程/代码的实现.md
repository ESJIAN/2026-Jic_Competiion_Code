### 二、核心逻辑：用代码控制硬件（电机、传感器等）

Webots 为不同语言提供**统一的编程接口（API）**，让代码能操作机器人的 “执行器（如电机）” 和 “传感器（如距离传感器）”，核心步骤是：

#### 1. 获取设备

通过 “设备名称”（需与场景树中电机、传感器的 `name` 属性一致），调用 API 函数获取设备对象。

- 示例（C++ 获取电机）：`Motor *leftMotor = robot->getMotor("left wheel motor");`
- 示例（Python 获取电机）：`left_motor = robot.getDevice("left wheel motor");`

#### 2. 设置控制指令

- **控制电机（执行器）**：可设置**位置**（如让电机旋转到指定角度）、**速度**（如让轮子持续以某转速转动）等。
    - 位置控制示例（C++）：`leftMotor->setPosition(10.0);`（让电机旋转 10 弧度后停止）。
    - 速度控制示例（Python）：
        
        python
        
        ```python
        left_motor.setPosition(float('inf'))  # 设为“速度控制”模式（位置无穷大）
        left_motor.setVelocity(0.3 * 6.28)    # 设为最大转速的 30%
        ```
        
- **读取传感器**：调用 API 读取传感器数据（如距离传感器的障碍物距离），用于后续逻辑判断（如 “检测到障碍物则转弯”）。

#### 3. 仿真循环

通过循环（如 `while (robot.step(TIME_STEP) != -1)`），让机器人以**固定时间步**（`TIME_STEP`，与世界的基础时间步一致）持续执行控制逻辑，模拟 “实时运行”。

### 三、不同语言的执行特点

Webots 支持的语言分为 “编译型” 和 “解释型”，执行环节有差异，但**控制逻辑完全一致**：

|语言类型|代表语言|执行特点|
|---|---|---|
|编译型|C/C++/Java|需先编译（生成可执行文件 / 字节码），再由 Webots 运行。|
|解释型|Python/MATLAB|无需编译，Webots 直接调用解释器运行脚本。|

### 四、仿真与验证

保存代码和世界文件后，点击 Webots 的「仿真」按钮，机器人会按照代码逻辑运动（如电机转动、传感器检测并反应）。若有错误，可通过 Webots 控制台查看输出（编译错误、运行日志等）进行调试。
