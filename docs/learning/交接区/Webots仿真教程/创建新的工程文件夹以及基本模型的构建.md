要知道的是**`webots`**的世界是由节点构成的，因此我们也可以通过调整各个节点的属性，来实现对其物理属性，空间属性的修改

下面以floor这个结点来看

![|335](https://youke1.picui.cn/s1/2025/10/17/68f22b98cf909.png)

1. ​**​`translation 0 0 0`​**​
        ​**​修改的是：位置​**​
        ​**​解释​**​：这三个数字分别代表物体在三维空间中的X、Y、Z坐标。`0 0 0`表示地板位于场景的世界中心原点。
2. 2.
    ​**​`rotation 0 0 1 0`​**​
        ​**​修改的是：旋转角度​**​
        ​**​解释​**​：这四个数字通常表示一个旋转轴和旋转角度。`0 0 1 0`表示围绕Z轴（0,0,1）旋转0弧度，即地板是水平的，没有旋转。
3. 3.
    ​**​`name "floor"`​**​
        ​**​修改的是：对象名称​**​
        ​**​解释​**​：这是在场景中标识这个对象的唯一名称，方便在其他地方引用或查找。
4. 4.
    ​**​`contactMaterial "default"`​**​
        ​**​修改的是：物理材质​**​
        ​**​解释​**​：这定义了当地板与其他物体发生碰撞时的物理属性（如摩擦力、弹性）。这里使用的是名为“default”（默认）的物理材质。
5. 5.
    ​**​`size 10 10`​**​
        ​**​修改的是：物理碰撞体积的尺寸​**​
        ​**​解释​**​：这定义了地板作为一个物理实体（用于碰撞检测）的宽度和长度。`10 10`表示它是一个10x10单位大小的平面。
6. 6.
    ​**​`tileSize 0.5 0.5`​**​
        ​**​修改的是：纹理贴图的平铺尺寸​**​
        ​**​解释​**​：这定义了地板外观纹理的重复密度。`0.5 0.5`表示纹理在宽度和长度方向上每0.5个单位就重复一次。数值越小，纹理图案就越密集。
7. 7.
    ​**​`appearance Parquetry`​**​
        ​**​修改的是：视觉外观​**​
        ​**​解释​**​：这是最重要的视觉参数。它指定了地板表面看起来是什么样子。`Parquetry`意为“拼花木地板”，所以这个地板会呈现出木地板的视觉效果。

我们会发现这个物块都不动，为啥呢，很简单，我们没有给其上`物理属性`

![](https://youke1.picui.cn/s1/2025/10/17/68f23b19877c2.png)

这两个，上面的是`物理边界`，有了他才会出现碰撞之类的活动，下面的是`物理属性`

但是我们赋予其物理属性时应该要明确我们要让哪一个物体有物理属性

因此我们应该定义其`DEF`，我们为其起个名字

![](https://youke1.picui.cn/s1/2025/10/17/68f23c6a56b4a.png)

![](https://youke1.picui.cn/s1/2025/10/17/68f23d41bd304.png)
