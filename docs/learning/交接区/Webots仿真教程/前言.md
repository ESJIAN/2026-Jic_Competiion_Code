>  **`Webots`**是一款**开源、跨平台的机器人仿真软件**，主要用于机器人的建模、编程和仿真测试。它由`瑞士联邦理工学院（EPFL）`于 1996 年开发，后由 `Cyberbotics 公司`持续维护，2018 年开源后广泛应用于工业、教育和科研领域。

### 核心功能与特点：

1. **多领域仿真**：支持轮式机器人、工业机械臂、无人机、自动驾驶汽车等各类机器人模型，可模拟室内外环境。
2. **多语言编程**：控制器可使用 C/C++、Python、Java、MATLAB 或 ROS 编写，适配不同开发需求。
3. **物理与图形引擎**：集成 ODE 物理引擎（处理碰撞、摩擦等）和 OpenGL 渲染引擎，提供真实的物理模拟与 3D 可视化。
4. **跨平台兼容**：支持 Windows、Linux、macOS 系统，且可导出仿真为 HTML、视频等格式，甚至通过浏览器在线运行。

### 常见用途：

- **教育**：机器人学课程教学、算法验证（如避障、路径规划）。
- **科研**：AI 与控制算法研究、多机器人协作仿真。
- **工业**：工厂自动化设计、自动驾驶车辆开发、机器人原型测试。
