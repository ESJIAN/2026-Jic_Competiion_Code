## 2. 运动模块

>我们通过小车运动时是通过轮子的`旋转`，而轮子的选择是建立在有`电机`，且在`一条轴`上实现的，所以我们要想让轮子转起来，就是要为轮子`建立旋转轴`，然后在`旋转轴上加电机`

`先做轮子`，做好后我们再开始

### 2.1 轴

![](https://youke1.picui.cn/s1/2025/10/18/68f3460909128.png)

我们依旧在`Robot`下的`children`处加`HingeJoint（铰链关节）`，不过这也不是说轴和轮子在世界树是同级的，后面我们会将轮子弄到轴节点的子节点中

![](https://youke1.picui.cn/s1/2025/10/18/68f346f21bca5.png)

可以看到有3个子节点
1. **`jointParameters`**：
    
    是关节的**参数配置对象**，用于定义铰链关节的特性（如旋转限制、阻尼、弹力等）。显示为 `NULL`，说明当前关节未初始化参数，或没有为它设置特定的关节参数。
    
2. **`device`**：
    
    通常关联**关节的控制 / 执行装置**（比如驱动关节运动的电机、执行器，或是负责关节逻辑的 “设备” 模块），用于驱动或调控关节的行为。
    
3. **`endPoint`**：
    
    代表关节连接的**末端对象 / 端点**（比如铰链关节另一端要连接的刚体、结构端点）。显示为 `NULL`，说明当前关节还未指定要连接的末端目标。

我们先双击第一个节点

![](https://youke1.picui.cn/s1/2025/10/18/68f347a89858e.png)

只能选择这个`铰链关节参数`，选择添加

![](https://youke1.picui.cn/s1/2025/10/18/68f348d4444c1.png)

我们直接把轮子的整个节点剪切到`endPoint`，注意是剪切，不是复制，不然就有两个一模一样且在同一位置的的轮子了

下一步我们让其中心与轮子的中心`重合`，且确定轴的方向

我们先让其显示`世界的3维坐标`

![](https://youke1.picui.cn/s1/2025/10/18/68f34a02bd6b8.png)

我们把轮子的中心的位置（`translation`）复制到`anchor`

然后我们将axis的值改为你要绕的轴，`例如我要让他按x轴（看世界坐标）转，那就把x改为1，其他的改为零`

这样我们的轴就构建好了

### 2.2 电机

我们点击HingeJoint下的device

![](https://youke1.picui.cn/s1/2025/10/18/68f34bf21f603.png)

我们选择上面的这个电机

- **`Brake（制动器）`**：用于对机械结构进行制动（控制停止运动）的组件。
- **`PositionSensor（位置传感器）`**：用于检测机械部件位置信息的传感器。
- **`RotationalMotor（旋转电机）`**：右侧说明显示，它可被机器人控制器程序调用，以围绕自身铰链轴产生旋转运动。

这样我们就完成了一个轮子的构建
